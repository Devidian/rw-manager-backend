# Manager backend 0.9.0-rc.1

This release candidate adds super-admin review and transactional merging of public master-list server duplicates. Strong matches share server name, short name, map, game mode and OS; possible matches share the latter four. No server is merged automatically. The oldest ID remains canonical, former IDs resolve for links, and the import retains the canonical ID at its current endpoint without claiming a reused old address.

Requires MongoDB replica-set transactions for merging and the existing `SUPER_ADMIN_ID` setting. Deploy this backend before frontend 1.9.0-rc.1. Back up MongoDB before any real merge; a previous backend image cannot restore merged source records or discarded overlapping statistic buckets. Roll back the images to backend 0.8.0 and frontend 1.8.1 if runtime checks fail before a merge.

Validation: TypeScript build and 49 test suites with 228 passing tests, including the configured coverage gate. Runtime acceptance of real candidate groups and the first merge remains pending.
