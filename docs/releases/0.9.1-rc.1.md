# Manager backend 0.9.1-rc.1

Player-server history now requires a valid session even when general server
reads are public. Guests receive masked Steam IDs in public storage/data JSON
responses and server-status live WebSocket messages; authenticated users retain
full IDs. JSON responses that vary by authentication are not cached.

Deploy this backend before Manager frontend 1.9.1-rc.1. This RC changes only
outgoing data; stored IDs and statistics remain intact. Roll back to backend
0.9.0 and frontend 1.9.0 together if testing fails. Existing game-server APIs
outside Manager are not affected.

Validation: TypeScript build and all 51 Jest suites / 240 tests including the
coverage gate and guest/authenticated WebSocket integration. Verify login,
history HTTP 401/200, and masked guest REST and live responses in the test
environment.
