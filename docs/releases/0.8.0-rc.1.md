# Manager backend 0.8.0-rc.1

This release candidate stores additional public Global Intercom channel subscriptions on authenticated users. `PATCH /api/auth/self/intercom-channels` validates and normalizes channel names; login and session validation return the saved array.

Legacy user records default to `global` and `web`. The change is additive and requires no database migration. Older frontend versions continue to work. Deploy this backend before frontend 1.8.0-rc.1. Roll back to backend 0.7.1-rc.2 if needed; the added user field remains inert to the older version.

Validation: TypeScript build and backend tests.
