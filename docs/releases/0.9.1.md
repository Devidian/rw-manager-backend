# Manager backend 0.9.1

This stable release includes the accepted player-profile privacy RC. Player-server history requires a valid session. Anonymous REST and server-status WebSocket responses mask Steam IDs to their first and last digit; authenticated users retain full IDs. Authentication-dependent JSON responses are not cached.

Deploy before Manager frontend 1.9.1. No stored IDs, statistics, or schema are changed. For image rollback, restore backend 0.9.0 and frontend 1.9.0 together; the pre-RC Compose and MongoDB backups are recorded in the workspace rollout handoff.

Validation: backend RC.1 passed the TypeScript build, 51 Jest suites / 240 tests including the coverage gate and GitHub CI. On the public RC deployment, guest history returned HTTP 401, anonymous server responses contained masked IDs and no complete Steam IDs, and backend, frontend, and MongoDB were healthy with zero restarts. Signed-in profile access and guest behavior were accepted by the user on 2026-11-13.
