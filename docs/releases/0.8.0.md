# Manager backend 0.8.0

This stable release includes the accepted 0.8.0 release candidates: saved public Global Intercom channel subscriptions, optional satellite map metadata, cached public player-server history with playtime, and server-side Steam persona lookup. Steam sign-in now verifies signed OpenID callbacks, the frontend callback origin, and nonce freshness before issuing a session.

Requires `STEAM_OPENID_RETURN_ORIGIN` set to the frontend HTTPS origin. `STEAM_API_KEY` is optional and belongs only on the backend. Deploy the backend before Manager frontend 1.8.0. Existing MongoDB records remain compatible; no schema migration is required. Roll back the Manager backend and frontend together to the last accepted RC pair if necessary.

The 0.8.0-rc.3 backend passed 47 test suites, 217 tests, TypeScript build, and the coverage gate. Production RC validation confirmed healthy startup, rejection of an invalid OpenID callback, and successful server-side Steam profile lookup. The user confirmed a real Steam login after rotating the key.
