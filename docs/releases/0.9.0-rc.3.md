# Manager backend 0.9.0-rc.3

Prevents an in-flight, long-running server query refresh from recreating source records after an administrator merges them. Existing server snapshots now update without upsert; explicit new server creation and newly imported master-list endpoints still insert records. The master-list loop also distinguishes new endpoints from already stored ones before saving. This release follows 0.9.0-rc.2 and does not require a frontend update.

The six stale alias records observed after the first test merge have no pinned users or remaining statistic buckets. Preview and apply `scripts/cleanup-recreated-server-aliases-20261110.js` only after deploying this backend; verify no alias records or buckets reappear. Preserve the pre-repair backup for rollback.

Validation: TypeScript build, 50 Jest suites, 235 tests, configured coverage gate, and the focused deleted-source regression tests.
