# Manager backend 0.8.0-rc.3

This release candidate resolves Steam persona names on the backend with an optional server-only `STEAM_API_KEY`. Steam OpenID login and account connection now require a signed, fresh assertion checked against Steam before a session is issued. The backend also checks the callback origin and rejects replayed nonces.

Set `STEAM_OPENID_RETURN_ORIGIN` to the frontend HTTPS origin and move `STEAM_API_KEY` from the frontend container to the backend. Deploy this backend before frontend 1.8.0-rc.7. A Steam profile lookup failure falls back to a generated username; unavailable OpenID verification rejects login. Roll back both Manager services together to backend 0.8.0-rc.2 and frontend 1.8.0-rc.6 if needed.

Validation: TypeScript build and 47 test suites with 217 passing tests, including the coverage gate and signed, tampered, stale and replayed OpenID assertions.
