# Manager backend 0.8.0-rc.2

This release candidate accepts optional satellite map metadata and provides cached public player-server history with available playtime. It retains all 0.8.0-rc.1 Global Intercom channel behavior. The history endpoint is read-only; existing server records gain only the additive `knownPlayers` cache fields used by this feature.

Deploy after renderer 0.1.5-rc.3 and before frontend 1.8.0-rc.2. Older renderer metadata remains compatible. Roll back to backend 0.8.0-rc.1 if needed; the added cached fields remain inert.

Validation: TypeScript build, 45 test suites and 213 tests including the CI coverage gate. Verify the live `/health` route and a player history request after deployment.
